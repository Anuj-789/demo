# 📖 About the Project

**St. Mary Convent School Website** is a modern, responsive, and user-friendly school website designed to provide students, parents, and visitors with easy access to essential school information.

The website showcases the school's vision, facilities, admission process, announcements, gallery, and contact details through an attractive and responsive interface. It focuses on creating a professional online presence while ensuring a smooth browsing experience across all devices.
